---
titel: Gedankenspiele
beschreibung: Was wäre, wenn …?
max: 20
tags: [leicht]
reihenfolge: 6
---

- Haben Sie eine geheime Superkraft? (Oder eine, die Sie gerne hätten?)
- Wenn Sie ein Tier sein könnten, welches wären Sie?
- Was würden Sie tun, wenn Sie einen Tag unsichtbar wären?
- Wie würde ein perfekter Tag für Sie aussehen?
- Wenn Sie eine Woche Zeit hätten, was würden Sie tun?
- Wenn Sie morgen irgendwohin fliegen könnten, wohin ginge der Flug?
- In welcher Stadt würden Sie gerne mal für ein Jahr leben?
- Wenn Sie eine Sprache sofort lernen könnten, welche wäre das?
- Welches Talent hätten Sie gern?
- Was wäre Ihr Traumjob?
- Wenn Sie ein kleines Café eröffnen würden, was würden Sie dort verkaufen?
- Wenn Sie eine Band gründen würden, wie würde sie heißen?
- Wenn Sie eine Woche nur ein Lied hören dürften, welches wäre das?
- Wenn Sie Influencer:in wären: Was wäre Ihr Thema?
